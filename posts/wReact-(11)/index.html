12.11 Home 페이지 구현하기 2. 기능

  • 헤더의 양 화살표를 누르면 Title 실시간으로 변경
    • 가변적인 값은 useState로 관리
    • getMonth()는 0부터 시작하므로 +1 필요
  • 해당 달의 일기만 리스트업 하도록 필터링 필요
    • getMontylyData: createDate의 값이 이번 달인 것만 필터링
      • pivotDate를 기준으로 필터링
      • beginTime: pivotDate달의 1일, 0시, 0분, 0초
        -getTime(): 비교를 위해 숫자값 형태로 저장
      • endTime: pivotDate+1달의 0일(전 달의 마지막 날), 23시, 59분, 59초
    • montlyData를 통해 data Props를 DiaryList컴포넌트에 전달
      • 리스트로 컴포넌트를 렌더링 할 때 각각 모든 값에 키값(item.id) 필요.
        map메서드 통해 DiaryItem컴포넌트 에 전달
  • 이미지 섹션이나 info 섹션을 클릭했을 땐 Diary의 Info 페이지로, 수정하기를 클릭했을 땐 Edit 페이지로
    • DiaryItem컴포넌트에서 useNavigate: 페이지를 이동시키는 기능. 각 id에 따라 세부페이지로 이동
  • 새 일기 쓰기 버튼 클릭 시 작성 페이지로 이동
    • DiaryList컴포넌트에서 useNavigate
  • 정렬 버튼 기능(최신순/오래된순)
    • DiaryList 컴포넌트에서 마찬가지로 가변적인 값은 useState로 관리
      • onChangeSortType함수를 통해 바뀔 때마다 sortType에 저장,
        getSortedData 함수에 toSorted(정렬된 새로운 배열 반환)라는 메서드를 통해 정렬 적용

12.17 웹 스토리지 이용하기

  • 웹 스토리지(Web Storage): 웹 브라우저 내장 DB
    • SessionStorge
      • 브라우저 탭 별로 데이터를 보관
      • 탭이 종료되기 전에는 데이터 유지
      • 탭이 종료되거나 꺼지면 데이터 삭제
    • LocalStorage
      • 사이트 주소별로 데이터 보관
      • 사용자가 직접 삭제하기 전까지 데이터 보관
  • 앱 컴포넌트의 data를 저장하고 불러오기
    • 앱을 생성 / 수정 / 삭제하는 함수 reducer에 추가
  • data를 불러오기 위해 기다려야 함: isLoading
    • Diary페이지 및 Edit페이지에서 새로고침 가능

12.18 배포 준비하기

  • 페이지 타이틀 설정하기
    • index.html의 title 태그 수정
    • 커스텀 훅을 생성해 useEffect를 활용하여 각 페이지에 맞게 해당하는 타이틀 설정
  • Favicon 설정하기
    • 이미즈는 public 폴더에 위치
    • index.html에서 rel="icon" 태그의 링크에 파비콘 이미지 링크를 추가
  • 오픈 그래프 태그 설정하기
    • 오픈 그래프: 웹사이트의 링크를 공유할 때 썸네일, 제목 등의 정보를 노출하는 것
    • index.html에서 meta 태그 추가
  • 프로젝트 빌드
    • npm run build

12.19 배포하기

  • 클라우드 서비스 이용
    • Vercel 추천!
      • 프론트엔드 갭라자를 위한 클라우드 서비스
      • React.js의 확장판 개념인 Next.js를 개발하는 회사
  • 프로젝트에서
    • npm install -g vercel
    • vercel login
    • vercel (반복하며 새롭게 배포 가능)
