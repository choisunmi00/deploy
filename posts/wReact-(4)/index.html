2.6 반복문으로 배열과 객체 순회하기

  • 순회(iteration): 배열, 객체에 저장된 여러개의 값에 순서대로 하나씩 접근하는 것
  • 배열 순회
    • 배열 인덱스와 for문
      • for(let i=0; i < arr.length; i++) { }
    • for of 반복문
      • for(let item of arr) { } : arr 값을 하나씩 item에 저장
  • 객체 순회
    • Object.keys 사용: 객체의 key 값만 뽑아 새로운 배열로 반환
    • Object.values 사용: 객체의 value 값만 뽑아 새로운 배열로 반환
    • for in 반복문
      • for(let key in person) { } : 객체(person)의 프로퍼티를 순서대로 key에 할당

2.7 배열 메소드 1. 요소 조작

  1. push: 배열의 맨 뒤에 새로운 요소를 추가하는 메서드
  2. pop: 배열의 맨 뒤에 있는 요소를 제거하고, 반환
  3. shift: 배열의 맨 앞에 있는 요소를 제거, 반환
  4. unshift: 배열의 맨 앞에 새로운 요소를 추가하는 메서드
    • shift 혹은 unshift는 push나 pop보다 느림: 맨 앞에 있는 요소를 제거하거나 추가하면 전체의 인덱스가 변경되므로 느리게 동작
  5. slice: 배열의 특정 범위를 잘라내 새로운 배열로 반환
    • 순서를 거꾸로 하고 싶다면 숫자 앞에 ‘-‘
  6. concat: 두개의 서로 다른 배열을 이어 붙여서 새로운 배열을 반환

2.8 배열 메소드 2. 순회와 탐색

  1. forEach: 모든 요소를 순회하면서, 각각의 요소에 특정 동작을 수행시키는 메서드
    • arr.forEach(function (item, idx, arr) {})
  2. includes: 배열에 특정 요소가 있는지 확인하는 메서드
    • 존재하지 않는다면 fasle반환
  3. indexOf: 특정 요소의 인덱스(위치)를 찾아서 반환하는 메서드
    • 존재하지 않는다면 -1반환
    • 얕은 비교를 기반
  4. findIndex: 모든 요소를 순회하며 콜백함수를 만족하는 특정 요소의 인덱스를 반환하는 메서드
    • 콜백함수를 만족: 콜백함수가 참을 반환
    • 깊은 비교 가능, 복잡한 타입의 객체 비교
  5. find: 모든 요소를 순회하며 콜백함수를 만족하는 요소를 찾고, 요소를 그대로 반환

2.9 배열 메소드 3. 배열 변형

  1. filter: 기존 배열에서 조건을 만족하는 요소들만 필터링하여 새로운 배열로 반환
  2. map: 배열의 모든 요소를 순회하면서, 각각 콜백함수를 실행하고 그 결과값들을 모아 새로운 배열로 반환
  3. sort: 배열을 사전순으로 정렬하는 메서드. (숫자값은 대소 기준으로 정렬하지 않음)
    • 숫자 대소 비교를 함께 하고 싶다면 콜백함수 추가 필요
    • 원본 배열을 정렬하는 것
  4. toSorted: 정렬된 새로운 배열을 변환하는 메서드
    • 원본 배열이 아닌 정렬된 새로운 배열을 반환
  5. join: 배열의 모든 요소를 하나의 문자열로 합쳐서 반환하는 메서드

2.11 동기와 비동기

  • 여러 개의 작업을 순서대로 한 번에 하나씩만 처리 = 동기적으로 처리
  • 자바스크립트는 동기적으로 코드를 처리
    • 단점: 하나의 작업이 오래걸릴 경우 해당 쓰레드가 그 작업을 끝낼 때 까지 다른 작업을 하지 못하기 때문에 전체 성능 저하 발생 ⟶ 멀티쓰레드 기법 활용 방법도 있지만, 자바스크립트 엔진에는 쓰레드가 1개 ⟶ 비동기
  • 비동기: 여러 개의 작업이 주어질 때 순서대로 처리하지 않는 것. 작업을 동시에 실행.
    • 비동기 작업들은 자바스크립트 엔진이 아닌 Web APIs에서 실행
    • Web APIs: 웹 브라우저가 직접 관리하는 별도의 영역
    • 자바스크립트 엔진 코드 실행 ⟶ 비동기 함수는 Web APIs로!: setTimeout 타이머와 콜백함수 같이 넘겨줌 ⟶ 자바스크립트 엔진은 바로 다음 코드 실행 ⟶ Web APIs는 타이머가 끝나면 콜백함수를 다시 자바사크립트 엔진에게 돌려줌 ⟶ 자바스크립트 엔진이 콜백함수 실행 ```js console.log(1);

    setTimeout(() => { console.log(2); }, 3000);

    console.log(3);

    // 1, 3, 2 순서로 출력 ```

// 음식을 주문하는 상황
function orderFood(callback) {
  setTimeout(() => {
    const food = "떡볶이";
    callback(food);
  }, 3000);
}

function cooldownFood(food, callback) {
  setTimeout(() => {
    const cooldownedFood = `식은 ${food}`;
    callback(cooldownedFood);
  }, 2000);
}

function freezeFood(food, callback) {
  setTimeout(() => {
    const freezedFood = `냉동된 ${food}`;
    callback(freezedFood);
  }, 1500);
}

orderFood((food) => {
  console.log(food);

  cooldownFood(food, (cooldownedFood) => {
    console.log(cooldownedFood);

    freezeFood(cooldownedFood, (freezedFood) => {
      console.log(freezedFood);
    });
  });
});

2.12 비동기 작업 처리하기 2. Promise

  • Promise: 비동기 작업을 감싸는 객체
    • 비동기 작업을 진행 단계에 따라 상태를 나눠 관리
      1. 대기(Pending): 비동기 작업이 진행중인, 아직 완료되지 않은 상태
        ⟶ resolve: 2. 성공(Flufilled): 비동기 작업이 성공적으로 마무리 된 상태
        ⟶ reject: 3. 실패(Rejected): 비동기 작업이 실패된 상태
  • executor: promise와 같이 비동기 작업을 실행하는 함수
  • then 메서드와 catch 메서드
    • promise chaining: 연달아서 사용가능

2.12 비동기 작업 처리하기 3. Async&Await

  • async: 어떤 함수를 비동기 함수로 만들어주는 키워드, 함수가 프로미스를 반환하도록 변환해주는 키워드
  • await: async 함수 내부에서만 사용이 가능한 키워드이며, 비동기 함수가 다 처리되기를 기다리는 역할
