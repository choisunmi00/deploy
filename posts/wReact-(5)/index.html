5.6 State로 상태관리하기

  • State: 현재 가지고 있는 형태나 모양을 정의. 변화할 수 있는 동적인 값
  • State를 갖는 React 컴포넌트는 State의 값에 따라 렌더링 되는 UI가 결정됨
    • Re-Render/Re-Rendering: 컴포넌트가 다시 렌더링 되는 상황 (즉, 앱 컴포넌트를 다시 호출)
    • State가 아닌 변수로 코드를 작성할 시 다시 렌더링 되지 않음. 화면에 변화가 생기지 않음
  • State가 있는 함수를 생성하기 위해서는 내장함수 useState 사용
    • 두 개의 요소를 반환. 첫번째는 현재 state값, 두번째는 상태변화함수(state를 변화시키는 함수)
    • 배열의 구조 분해 할당을 이용해 state, setState로 받는 것이 일반적

5.7 State와 Props

  • 자식 컴포넌트는 자신이 가진 state가 변경되지 않더라도 부모로부터 받는 Props가 변경되면 리렌더링

        • 관련이 없는 컴포넌트가 필요치 않게 리렌더링 될 수 있기에 서로 다른 컴포넌트로 분리 필요 (파일로도 분리 가능)

      import { useState } from "react"

  const Register=()=>{

      const [name, setName] = useState("이름");
      const [birth, setBirth] = useState("");
      const [country, setCountry] = useState("");
      const [bio, setBio] = useState("")

      const onChangeName = (e) => {
          setName(e.target.value);
      };

      const onChangeBirth = (e) => {
          setBirth(e.target.value);
      }

      const onChangeCountry = (e) => {
          setCountry(e.target.value)
      }

      const onChangeBio = (e) => {
          setBio(e.target.value)
      }

      return (
          <div>
              <div>
                  <input 
                  value={name}
                  onChange={onChangeName} 
                  placeholder="이름" 
                  />
              </div>
                
              <div>
                  <input 
                  value={birth}
                  onChange={onChangeBirth}
                  type="date" />
              </div>

              <div>
                  <select value={country} onChange={onChangeCountry}>
                      <option value="">선택하세요</option>
                      <option value="kr">한국</option>
                      <option value="us">미국</option>
                      <option value="uk">영국</option>
                  </select>
              </div>

              <div>
                  <textarea value={bio} onChange={onChangeBio} />
              </div>
                
          </div>
      );
  };

          import { useState, useRef } from "react"

  const Register=()=>{

      const [input, setInput] = useState({
          name: "",
          birth: "",
          country: "",
          bio: "",
      });
      const countRef = useRef(0);
      const inputRef = useRef();

      const onChange = (e) => {
          countRef.current++;
          console.log(countRef.current);
          setInput({
              ...input,
              [e.target.name]: e.target.value

          })
      }
                
      const onSubmit = (e) => {
          if(input.name === ""){
              inputRef.current.focus();
          }
      }

      return (
          <div>
              <div>
                  <input
                  ref={inputRef} 
                  name="name"
                  value={input.name}
                  onChange={onChange} 
                  placeholder="이름" 
                  />
              </div>
                        
              <div>
                  <input 
                  name="birth"
                  value={input.birth}
                  onChange={onChange}
                  type="date" />
              </div>

              <div>
                  <select name="country" value={input.country} onChange={onChange}>
                      <option value="">선택하세요</option>
                      <option value="kr">한국</option>
                      <option value="us">미국</option>
                      <option value="uk">영국</option>
                  </select>
                  {input.country}
              </div>

              <div>
                  <textarea name="bio" value={input.bio} onChange={onChange} />
                  {input.bio}
              </div>
                        
              <button onClick={onSubmit}>제출</button>
          </div>
      );
  };

  export default Register
  • useRef가 아닌 일반적인 자바스크립트 변수는 리렌더링이 될 때 모두 리셋되지만,
    useRef와 같은 특수한 변수들은 컴포넌트가 리렌더링 되더라도 다시 호출되지 않음.
    변수를 외부에 선언할 경우, 컴포넌트를 두 번 사용할 때 하나의 변수가 공유되기 때문에 의도대로 작동되지 않을 수 있음.

5.11 React Hooks

  • React Hooks: 클래스 컴포넌트의 기능을 함수 컴포넌트에서도 이용할 수 있도록 하는 메서드
    • 2017년 이전 리액트에서는 리액트의 모든 기능을 class 컴포넌트에서만 이용 가능.
      하지만 문법은 function 컴포넌트가 훨 간편했기에 확장.
    • useState, useRef 등 대략 20개
    • 함수 컴포넌트 내부에서만 호출 가능
    • 조건문, 반복문 내부에서는 호출 불가
      • 서로 다른 훅들의 호출 순서가 내부적으로 꼬일 수 있기에
    • Custom Hook 생성 가능
      • 접두사 use 사용

      };

      return [input, onChange];
