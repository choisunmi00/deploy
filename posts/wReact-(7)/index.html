7.1 라이프사이클이란?

  • 리액트 컴포넌트의 라이프사이클
    1. Mount
      • 탄생
      • ‘화면에 처음으로 렌더링’
      • 서버에서 데이터를 불러오는 작업 등 수행
    2. Update
      • 변화
      • ‘리렌더링’
      • 어떤 값이 변경되었는지 콘솔에 출력하는 작업 등 수행
    3. UnMount
      • 죽음
      • ‘화면에서 사라지고, 렌더링에서 제외’
      • 컴포넌트가 사용하던 메모리 정리 작업 등 수행
  • 라이프사이클 제어: 컴포넌트의 라이프사이클을 기준으로 다른 작업을 수행하도록 하는 것
    • 리액트 훅 useEffect 사용

7.2 useEffect 사용하기

  • useEffect: 리액트 컴포넌트의 사이드 이펙트를 제어하는 React Hook
    • 사이드 이펙트: 어떠한 동작의 부수적인, 파생되는 효과
    • 첫 번째 인수로는 콜백함수, 두 번째 인수로는 배열.
      • 배열의 값이 바뀌게 되면 콜백함수를 실행 = 배열에 의존
        ⟶ 이러한 배열을 의존성 배열, dependency array = deps

  • setCount와 같은 상태변화함수는 비동기로 동작.
    호출은 되더라도 완료는 되지 않기에 useEffect가 아닌 onClickButton에서 콘솔로 출력하도록 하면 그 전 count를 출력

  • 7.2

7.3 useEffect로 라이프사이클 제어하기

  • Mount
    • deps로는 빈 배열: 콜백함수는 처음 컴포넌트가 렌더링 될 때 외에는 실행 X
  • Update
    • deps를 생략: 콜백함수는 리렌더링 될 때마다 실행
    • 마운트 될 때 업데이트를 출력하고 싶지 않다면,
      현재 마운트 된 것인지 체크하는 useRef이용
  • UnMount
    • 나타났다 사라지는 컴포넌트 생성: Even
    • 클린업, 정리함수: useEffect의 콜백함수가 반환하는 함수. useEffect가 끝날 때 실행
  • 7.3

7.4 React 개발자 도구 사용하기

  • 크롬 확장 프로그램 ‘React Developer Tools’
    • 파일 URL에 대한 액세스 허용
    • Components 탭 사용 가능
      • props 및 state 확인 가능
      • 렌더링 될 때마다 하이라이팅 가능
