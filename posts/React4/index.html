onClick 쓰는 법

  • event handler
  • onClick={} 안에는 함수 이름을 넣어야 함(함수 만드는 문법 바로 넣어도 상관없음 () => {} 등)
    • ex) <h4>{글제목[0]}<span onClick={() => {console.log(1)} }> ❤️</span> {하트} </h4>
