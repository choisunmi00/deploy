배열 순회와 탐색 메소드

  1. forEach: 모든 요소를 순회하면서, 각각의 요소에 특정 동작을 수행시키는 메서드
    • arr.forEach(function (item, idx, arr) {})
    • 모든 요소에 동일한 작업을 수행할 때 주로 쓰인다.
      • 같은 요소 스타일 변경, 이메일 일괄 발송, 로그 출력 및 디버깅 등
  2. includes: 배열에 특정 요소가 있는지 확인하는 메서드
    • 존재하지 않는다면 fasle반환
    • 권한/상태/조건 확인할 때 주로 쓰인다.
      • 사용자 권한 검증, 장바구니 중복 상품 확인, 지원 기기 및 브러우저 확인 등
  3. indexOf: 특정 요소의 인덱스(위치)를 찾아서 반환하는 메서드
    • 존재하지 않는다면 -1반환
    • 얕은 비교를 기반
    • 간단하게 위치를 찾거나 존재를 확인할 때 주로 쓰인다.
      • 배열에서 특정 요소를 제거하거나 플레이리스트 현재 곡 위치를 반환할 때 등
  4. findIndex: 모든 요소를 순회하며 콜백함수를 만족하는 특정 요소의 인덱스를 반환하는 메서드
    • 콜백함수를 만족: 콜백함수가 참을 반환
    • 깊은 비교 가능, 복잡한 타입의 객체 비교
    • 복잡한 조건으로 위치를 찾을 때 주로 쓰인다.
      • 특정 ID 사용자의 정보를 업데이트하거나, 조건에 맞는 첫 번째 데이터 위치를 반환하는 등
  5. find: 모든 요소를 순회하며 콜백함수를 만족하는 요소를 찾고, 요소를 그대로 반환
    • 조건에 맞는 객체 자체가 필요할 때 주로 쓰인다.
      • 특정 상품 정보를 조회하거나, 현재 로그인하고 있는 사용자를 찾는 등

배열 변형 메소드

  1. filter: 기존 배열에서 조건을 만족하는 요소들만 필터링하여 새로운 배열로 반환
    • 조건에 맞는 항목들만 골라낼 때 주로 쓰인다.
      • 상품 필터링, ‘읽지 않는 메시지만 표시’와 같은 기능, 활성 사용자만 조회하는 등
  2. map: 배열의 모든 요소를 순회하면서, 각각 콜백함수를 실행하고 그 결과값들을 모아 새로운 배열로 반환
    • 모든 요소를 변형하여 새로운 배열을 만들 때 주로 쓰인다.
      • 세금이 포함된 최종 가격을 계산하거나, API형식을 프론트엔드용으로 변환하거나, 차트용 데이터 포맷을 변환하는 등
  3. sort: 배열을 사전순으로 정렬하는 메서드. (숫자값은 대소 기준으로 정렬하지 않음)
    • 숫자 대소 비교를 함께 하고 싶다면 콜백함수 추가 필요
    • 원본 배열을 정렬하는 것
    • 원본 배열을 직접 수정하기에 원본 데이터가 변경되어도 괜찮은 상황에 주로 쓰인다.
      • 성적 순으로 학생을 정렬하거나, 메뉴 항목을 알파벳순으로 정렬하는 등
  4. toSorted: 정렬된 새로운 배열을 변환하는 메서드
    • 원본 배열이 아닌 정렬된 새로운 배열을 반환
    • 새 배열을 생성하기에 원본 데이터를 보존해야 할 때 주로 쓰인다.
      • 대시보드 용으로 원본 데이터는 유지하되 정렬이 바뀔 때, 플레이리스트 정렬 옵션을 설정할 때 등
  5. join: 배열의 모든 요소를 하나의 문자열로 합쳐서 반환하는 메서드
    • 배열을 문자열로 합쳐 표현할 때 주로 쓰인다.
      • 태그 목록을 쉼표로 연결하여 사용자에게 보기 좋게 문자열을 생성하거나, 파일 경로 생성, 사용자 목록을 문장으로 만들 때 등
